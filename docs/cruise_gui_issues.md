## 1. 闭环平移/倒车的动作超时未扣除暂停时间

- 位置：`src/nav_demo/scripts/cruise_debug.py` 的 `CruiseWorker._align_to`。
- 现象：暂停期间会停车，但暂停时长计入该动作超时；长时间暂停后继续可能立即超时。
- 建议验收：分别在平移和倒车中暂停超过原动作超时，再继续；应保留暂停前的剩余执行时间。
- 注意：新加的总耗时/暂停时长统计与动作超时独立，计时修复不解决此问题。

## 2. 部分准备/转向失败后仍继续运动

- 位置：`CruiseWorker._run_plan` 中的倒车前对齐、倒车前转向、平移前转向和普通导航预转向等调用。
- 问题：部分 `_align_to` / `_rotate_to` 返回值被忽略，仅检查终止标志；失败后仍可能执行下一动作。
- 最近两次全程日志未出现相关失败；这是代码异常路径风险，不是已确认的现场故障。
- 建议验收：用模拟反馈制造准备/转向失败，确认后续运动被拦住并显示明确错误。

## 3. 定位与校准的安全保护不足

- `_map_pose` 未核查 TF 时间，定位缓存失败后保留旧值：应避免拿过期位姿持续闭环运动。
- 校准取全局最高分后直接发布 `/initialpose`：缺少置信度、对称解歧义、位姿跳变限制或人工确认。
- 雷达外参查询失败仍按零外参继续；坐标系名硬编码，未使用扫描消息和启动参数中的 frame。
- 校准与开始运动缺少双向互锁，也未验证车辆静止。
- 建议验收：模拟 TF 中断、缺外参、对称匹配和校准期间点击开始；应拒绝可疑结果或阻止运动，而不是静默继续。
