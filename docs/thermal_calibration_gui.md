# 红外标定 GUI 实现规格（交接给 GUI 对话）

目标：在 `capture_photos.py` 的红外热像模式里加一个「标定」窗口，一次性求出
热像 32×24 → RGB 的单应 `H`，并在运行时把热点投到 RGB，结合 YOLO/窗户中心判层。

本文只描述规格和接口，不要求改 `mlx90640_ros` 的采集链路。绿框已经默认关闭
（`render_image(..., draw_box=False)`），楼层文字在底部 caption，标定时画面是干净的。

## 0. 先明确三件事

1. **H 只由两个相机的相对位姿决定**。车整体前后、左右、yaw 转动都不改变 H；
   只有 **pitch（车头俯仰）** 敏感。标一次，再用 2~3 个停位做一致性验证即可。
2. **标定热源任意**：加热铁片、暖宝宝、热风枪都行。唯一硬约束是热源必须贴在
   楼正面（与窗户同一平面），不能悬空或换平面。
3. **标定点不必是楼四角**。只要在楼面同一平面上分布开，6~9 个点即可。
   楼的四角/层线由 RGB 侧的 YOLO 或窗户中心负责，热源只服务标定。

## 1. 坐标系

| 量 | 定义 |
|---|---|
| IR 像素 | `(col, row)`，col 0..31、row 0..23；图像已按 `mirror_x=True` 水平镜像 |
| RGB 像素 | `(u, v)`，Dabai RGB 原始分辨率 |
| H | 3×3，`[u, v, 1]ᵀ ~ H · [col, row, 1]ᵀ`，列优先归一化 |

注意 OpenCV 的点是 `(x, y) = (col, row)`，不要传成 `(row, col)`。

GUI 预览是放大后的图，点击位置要**换算回原始像素**再入表：

```python
col = int(x_display / scale)     # IR：scale 为热像放大倍数
row = int(y_display / scale)
u = int(x_display * rgb_width / preview_width)    # RGB：按预览缩放比换算
v = int(y_display * rgb_height / preview_height)
```

## 2. 标定文件

路径：`~/Pictures/photo_capture/红外热像/calibration.json`

```json
{
  "version": 1,
  "H": [[h00, h01, h02], [h10, h11, h12], [h20, h21, h22]],
  "points": [[row, col, u, v], ...],
  "rms_px": 0.8,
  "ir_size": [32, 24],
  "rgb_size": [1280, 720],
  "mirror_x": true,
  "scale": 12,
  "created": "2026-11-13T16:00:00+08:00",
  "note": "标称停车位，铁片 8 点"
}
```

加载时校验 `ir_size`、`rgb_size`、`mirror_x` 与当前会话一致；不一致直接报错，
不要静默使用。`H` 缺失或点数少于 4 视为无效。

## 3. 窗口布局

在 `ThermalApp` 里加「标定」按钮，打开 `Toplevel`：

```
┌─────────────────────────┬─────────────────────────┐
│ IR 预览（可点击选点）    │ RGB 预览（可点击选点）   │
│ 顶栏：热点 (r,c) 温度    │ 顶栏：点击坐标 (u,v)     │
├─────────────────────────┴─────────────────────────┤
│ 点对表格：# / IR (r,c) / RGB (u,v) / 该点温度      │
├───────────────────────────────────────────────────┤
│ [自动热点] [采集当前点] [删除上一点] [清空]        │
│ [计算 H]  RMS: -- px   点数: 0/4+                  │
│ [保存] [加载] [验证] [关闭]                        │
└───────────────────────────────────────────────────┘
```

要求：

- **IR 预览点击 = 手动选点**，覆盖自动 `argmax`；点击后画十字并显示 `(r,c)`。
- 默认显示自动热点（`frame.hotspot`），但「自动热点」按钮可切回自动。
- **ROI 输入**：`r0,c0,r1,c1`（半开），用于排除楼顶上方温度不低的排插。
  ROI 变化时重建 `ThermalSession(roi=...)`（当前没有 set_roi），保证运行时
  `find_hotspot` 也不受排插影响。
- 表格行点击可回看该点；「删除上一点」删最后一行。
- 状态栏显示点数、RMS、H 是否有效。

## 4. 采集流程

1. 车停到标称位置，相机锁死；**标定全程不动车**。
2. 热源贴楼正面一点，等 1~2 s 稳定。
3. 在 IR 预览确认热点位置（自动或手动点选），在 RGB 预览点热源中心。
4. 点「采集当前点」，表格加一行 `(row, col, u, v)`。
5. 移动热源，重复 6~9 次，覆盖楼面上、中、下、左、右；不要全排成一条线。
6. 点「计算 H」：`cv2.findHomography(ir_pts, rgb_pts, 0)`，显示 RMS。
7. 点「验证」：当前热点经 H 投到 RGB，画圈并标出投影坐标。
8. 点「保存」写 `calibration.json`。

推荐点位：

| 点 | 热源放哪 | RGB 点哪 |
|---|---|---|
| 1 | 当前热源窗户 | 该窗户中心（判层真实位置） |
| 2~5 | 楼面四角内侧 2~3 cm | 热源中心 |
| 6~9 | 其他窗户中心 / 楼面中间 | 对应位置 |

## 5. 计算与判定

```python
import cv2
ir_pts = np.array([[col, row] for row, col, u, v in points], np.float32)
rgb_pts = np.array([[u, v] for row, col, u, v in points], np.float32)
H, mask = cv2.findHomography(ir_pts, rgb_pts, 0)
```

- 至少 4 点；6~9 点更稳。点数少于 4 禁用「计算」。
- RMS 用重投影误差：`sqrt(mean(||project(ir_i) - rgb_i||²))`，**目标 < 2~3 px**。
- 有外点可改用 `cv2.RANSAC`，但标注点少时不建议，先检查是不是点错了。

投影函数：

```python
def project(H, col, row):
    p = H @ np.array([col, row, 1.0])
    return p[0] / p[2], p[1] / p[2]
```

## 6. 运行判层

热点投到 RGB 后，用 YOLO 或窗户中心定层：

1. YOLO 检测每层窗户框，取每层三个窗户中心 `y` 的中位数作为该层中心 `y_floor`。
2. 热点投影 `v` 与各 `y_floor` 比较，取最近的一层。
3. 更稳的做法：判断投影点 `(u, v)` 落在哪个窗户框内，直接取该框所属楼层；
   落在框外再退回最近层中心。

比赛只开一个热源时，热点唯一，不存在多目标歧义。

## 7. 跨停位一致性验证（标定完必做）

在标称位、前后各 5 cm、yaw ±2°、pitch ±1° 各停一次，用**同一个 H** 把同一点
热源投到 RGB，记录 `(u, v)` 变化：

- 偏差 < 5 px：H 稳定，不用重标；
- 偏差明显变大：先检查 pitch 和相机支架，再考虑重标。

把每次的停车位姿（odom/map + IMU pitch/yaw）记在标定 JSON 的 `note` 里，便于复现。

## 8. YOLO 数据采集矩阵

判层用的楼体数据要覆盖停车浮动，建议：

| 维度 | 档位 | 数量 |
|---|---|---|
| 前后 | 标称、±5 cm | 3 |
| 左右 | 标称、±3 cm | 3 |
| yaw | 标称、±2° | 3 |
| pitch | 标称、±1° | 3 |
| 光照 | 开灯 / 关灯 / 自然光 | 3 |
| 热源 | 单层开 / 全关 | 2 |

不用做满笛卡尔积，挑 9~15 个组合，每组 5~10 张，重点覆盖边界。标注时把窗户框
标完整，贴图窗户反光少，比真实玻璃好标。

## 9. 注意事项

- **必须静止拍摄**：IR 只有 1 Hz，车动时热像和 RGB 会差半秒以上。
- **铁片贴楼正面**，加热到稳定再拍；不要悬空、不要换平面。
- **镜像**：`mirror_x=True` 时 IR 已是镜像坐标，标定和运行必须一致；
  改镜像设置后旧 `H` 作废。
- **ROI 排除排插**：楼顶上方排插温度不低，运行时要让 `argmax` 只落在楼体范围。
- **相机支架碰过就重标**，H 没有自检能力。

## 11. 代码落点

- `capture_photos.py`：`ThermalApp` 加「标定」按钮和 `CalibrationWindow`，
  复用现有 IR/RGB 预览控件。
- 标定文件读写、`project()`、`rms()` 可以单独放一个小模块（例如
  `photo_capture/scripts/thermal_calibration.py`），方便单测。
- 不要改 `mlx90640_ros` 的采集/解码链路；只调用 `ThermalSession.latest()`、
  `floor_table`、`save_snapshot` 这些公开接口。
